# Hackathons & visibility channels

Researched 2026-08-18, date-verified against live pages (stale 2024/2025 events
excluded). Announced pickings for Sep 2026–Feb 2027 are honestly thin; the
best-fit event class isn't announced yet. The play is a sequence, not one event.

## The recommended sequence

1. **AI Builders Hackathon** — online, **Aug 21 – Sep 15, 2026**, $33.9K pool,
   explicitly welcomes autonomous agents + developer tools, no required stack.
   Best verified near-term fit; a low-effort warm-up right after Sep 3.
   Caveat: small/unproven organizer — treat prize claims with mild skepticism.
   <https://ai-builders-hackathon-2026.devpost.com/>
2. **Hacktoberfest 2026 (October)** — theme is literally open-source AI. The
   move: **register the repo as a participating project** with good-first-issues
   (e.g. "write a surface") to recruit exactly the fork-and-extend community
   this project is designed for. Registration opens late Sep.
   <https://hacktoberfest.com/>
3. **Product Hunt launch** when demo-ready — rolling, arguably the
   highest-leverage channel for an OSS macOS AI client.
4. **Watch for the next "Built with Opus" hackathon** (Cerebral Valley ×
   Anthropic) — recurring official virtual hackathons tied to Opus releases
   (4.6 ed. Feb 2026, 4.7 ed. Apr 2026; ~500 selected of 13K+, $100K pool,
   demo to the Claude Code team). **The event this project was practically made
   for** — judged by the people who built the SDK it's built on. Next edition
   likely with the next Opus release; unannounced. Watch
   <https://cerebralvalley.ai/hackathons>, @cerebral_valley, @claudeai.
5. **DeveloperWeek 2027 Hackathon** — **Jan 25 – Feb 11, 2027**, online +
   Santa Clara finale, $12.5K+, same organizer/format as API World but
   dev-tools-skewed, so odds of a fitting sponsor track are better.
   <https://www.developerweek.com/hackathon/>
